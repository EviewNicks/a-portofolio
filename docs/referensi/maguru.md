# Maguru: Gambaran Besar

## Apa Itu Maguru?

**Maguru** adalah platform pembelajaran digital berbasis AI yang dirancang untuk membantu pembelajar teknologi menguasai kompetensi nyata melalui pengalaman belajar yang personal, adaptif, dan berorientasi pada penguasaan kemampuan (mastery learning), bukan sekadar menyelesaikan materi.

Secara sederhana:

> Maguru bukan platform yang hanya memberikan materi untuk dibaca.
>
> Maguru adalah platform yang memastikan pengguna benar-benar memahami, menguasai, dan mampu menerapkan kompetensi yang dipelajari.

---

# Masalah yang Ingin Diselesaikan Maguru

## Kondisi Saat Ini

Sebagian besar platform pembelajaran online masih menggunakan pendekatan yang relatif statis:

```text
Materi
↓
Video / Artikel
↓
Quiz
↓
Selesai
```

Semua pengguna mendapatkan:

* Materi yang sama
* Urutan belajar yang sama
* Quiz yang sama
* Pendekatan belajar yang sama

Padahal kenyataannya:

### User A

Sudah memahami dasar Python.

### User B

Belum memahami variabel dan tipe data.

### User C

Sudah bisa membuat project sederhana.

Namun ketiganya tetap dipaksa mengikuti materi yang sama.

Akibatnya:

* User cepat bosan.
* User yang sudah mahir merasa waktu terbuang.
* User yang tertinggal semakin kesulitan.
* Tingkat penyelesaian course rendah.
* Kompetensi yang dikuasai tidak maksimal.

---

# Filosofi Utama Maguru

## Learning-First

Banyak platform fokus pada:

> Berapa banyak materi yang selesai dipelajari.

Maguru fokus pada:

> Apa yang benar-benar berhasil dikuasai pengguna.

Contoh:

Platform biasa:

```text
Course selesai = sukses
```

Maguru:

```text
Kompetensi dikuasai = sukses
```

---

## Competency-Based Learning

Maguru tidak mengukur keberhasilan dari:

* jumlah video ditonton
* jumlah halaman dibaca

Tetapi dari:

* kemampuan yang telah dikuasai
* kemampuan yang dapat diterapkan
* kemampuan membuat project nyata

---

## Personalized Learning

Setiap orang belajar dengan cara berbeda.

Contoh:

### User A

Lebih mudah memahami konsep melalui analogi.

### User B

Lebih mudah memahami konsep melalui praktik langsung.

### User C

Lebih suka penjelasan teknis yang mendalam.

Maguru berusaha menyesuaikan cara penyampaian materi dengan kebutuhan masing-masing pengguna.

---

## Micro-Learning

Materi tidak diberikan dalam blok besar.

Sebaliknya:

```text
Konsep Besar
↓
Sub Konsep
↓
Unit Kecil
↓
Langkah Kecil
```

Tujuannya:

* lebih mudah dipahami
* tidak membebani pengguna
* meningkatkan retensi belajar

---

## Scaffolding Learning

Materi diberikan secara bertahap.

Contoh:

Tidak langsung:

```python
Membuat REST API dengan FastAPI
```

Tetapi:

```text
Variabel
↓
Function
↓
Class
↓
Module
↓
HTTP
↓
API
↓
FastAPI
```

Setiap tahap membangun fondasi untuk tahap berikutnya.

# Produk Inti Maguru

Maguru terdiri dari tiga lapisan utama.

---

# Layer 1: Course Knowledge Base

Ini adalah fondasi Maguru.

Berbeda dari chatbot biasa.

Maguru memiliki:

```text
Course
↓
Materi Terstruktur
↓
Knowledge Base
↓
RAG
```

Materi dibuat oleh:

* Internal Expert
* Kurasi berbagai sumber berkualitas

---

Contoh:

Course Python Pemula:

```text
1. Variabel
2. Tipe Data
3. Operator
4. Percabangan
5. Loop
6. Function
7. OOP
8. Project
```

Semua materi tersimpan dalam knowledge base.

---

# Layer 2: AI Co-Teacher

Ini adalah jantung Maguru.

AI bukan chatbot generik.

AI memahami:

* struktur course
* tujuan pembelajaran
* kompetensi target
* progres pengguna

---

Contoh:

User bertanya:

> Mengapa kita menggunakan function?

AI tidak menjawab secara generik.

AI menjawab berdasarkan:

* materi course
* posisi user saat ini
* kompetensi yang sedang dipelajari

---

# Layer 3: Adaptive Learning Engine

Ini yang membuat Maguru berbeda.

---

## Assessment Awal

Saat user masuk course:

AI melakukan pemetaan:

* pengalaman
* tujuan belajar
* gaya belajar
* kemampuan awal

---

## Skill Assessment

User mengerjakan quiz awal.

Tujuannya:

Mengidentifikasi:

```text
Sudah Dikuasai
Belum Dikuasai
Perlu Penguatan
```

---

## Personal Learning Path

AI membuat jalur belajar berbeda untuk setiap user.

Contoh:

### User A

Sudah paham dasar Python.

Learning path:

```text
Skip Dasar
↓
Masuk OOP
↓
Masuk Project
```

---

### User B

Masih pemula.

Learning path:

```text
Variabel
↓
Tipe Data
↓
Operator
↓
Latihan
```
